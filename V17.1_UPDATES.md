# v17.1 Updates - Addressing Smoke Test Feedback

## Overview

Based on @nurdymuny's detailed feedback from the smoke test, v17.1 implements critical improvements to address three main failure modes:

1. **κ_gap going negative/zero** - Small sample sizes + overly fine bins
2. **η_max = 1.0** - Bins too fine for MCMC chain dynamics
3. **A2S failing** - Single observable insufficient for sufficiency test

## Changes Implemented

### 1. More Robust Quantile Strategy (κ_gap Fix)

**Problem:** Using Q_0.1/Q_0.9 with small samples led to noisy tail estimates, causing κ_gap to go negative when vacuum and non-vacuum bins overlapped.

**Solution:** Changed default quantiles to Q_0.2/Q_0.8 (less tail-sensitive).

```python
# v17: Always used Q_0.1/Q_0.9 for n >= 20
if n >= 20:
    return percentile(values, [10, 90])

# v17.1: Use Q_0.1/Q_0.9 only for high occupancy (n >= 50)
if n >= 50:
    return percentile(values, [10, 90])  # Only when very well-sampled
elif n >= 10:
    return percentile(values, [20, 80])  # Default for robustness
```

**Impact:**
- Reduces sensitivity to tail noise in bins with 20-50 configs
- Makes κ_gap more stable at finite N
- Still uses Q_0.1/Q_0.9 when bin occupancy is high enough

**File:** `rest_of_validation_gpu_v17.py`, lines 649-677

### 2. Coarser ε_disc for η Measurement (η_max Fix)

**Problem:** η_max = 1.0 at ε=0.20 meant bins were too granular - almost every MCMC step exited the bin.

**Solution:** Use separate coarser binning (ε_disc = 0.30) for η measurement while keeping fine resolution for κ/χ ladder.

```python
# v17: Measured η at same resolution as κ
bins, assignments = assign_bins(configs, eps_skel, eps_disc)
eta_mean, eta_max = compute_eta_from_chain(configs, bins, assignments)

# v17.1: Use coarser ε_disc for η to ensure bins persist over MCMC steps
eta_eps_disc = 0.30  # Coarser than refinement ladder
eta_bins, eta_assignments = assign_bins(configs, eps_skel, eta_eps_disc)
eta_mean, eta_max = compute_eta_from_chain(configs, eta_bins, eta_assignments)
```

**Impact:**
- η_max should now be < 0.8 (bins persist over multiple steps)
- Separates dynamical quantity (η) from static separation (κ)
- Reference level for R calculation uses appropriate scale

**File:** `rest_of_validation_gpu_v17.py`, lines 1016-1032

## Summary of Smoke Test Issues Addressed

| Issue | v17 Behavior | v17.1 Fix |
|-------|--------------|-----------|
| κ_gap negative | Q_0.1/Q_0.9 at n=20+ | Q_0.2/Q_0.8 default, Q_0.1/Q_0.9 only at n≥50 |
